# Documentation développeurs

Cette page reste volontairement un point d'entrée : la référence technique complète (architecture, modèle de données, contrat réseau, API HTTP/WebSocket) vit dans le dépôt et reste la source de vérité — elle évolue avec le code, une copie ici serait vite désynchronisée.

- **[docs/ARCHITECTURE.md](https://github.com/FantasmaGlad/Bobine/blob/main/docs/ARCHITECTURE.md)** — stack, architecture multi-worker, modèle de données SQLite, canaux de diffusion, module radio, référence API HTTP/WebSocket, découverte réseau.
- **[Dépôt GitHub](https://github.com/FantasmaGlad/Bobine)** — code source, Issues, Discussions, Releases.

## Stack

- **Backend** — Python 3.11+, FastAPI + `uvicorn` (4 workers), SQLAlchemy, SQLite, Redis (bus d'état Pub/Sub, verrous distribués), APScheduler, `ffmpeg`/VA-API pour le décodage matériel.
- **Frontend** — Next.js (App Router, export statique servi par le backend en production), React, TypeScript, CSS vanilla avec 13 thèmes commutables à chaud, WebSockets.
- **Exploitation** — Debian 13, Chromium en kiosque (X11), `systemd`, `avahi-daemon` pour la découverte mDNS.
- **Installation** — `install.sh` (Bash, idempotent) ; un assistant d'installation graphique est en construction (`assistant/`, cœur Rust).

## Architecture en bref

Un seul mini PC sur le réseau local fait tourner le backend multi-worker (état partagé via Redis, verrous distribués pour éviter les courses entre workers au démarrage), le kiosque Chromium pour l'écran câblé, et sert l'interface Next.js (admin, cinéma membre, télécommande mobile) en pages statiques. Les autres écrans et appareils (écran réseau, remotes, PC d'admin) sont de simples navigateurs qui pointent vers le mini PC — aucun média ne quitte le réseau local.

## Développement local

Prérequis : Node.js ≥ 20, Python ≥ 3.11, Redis local actif.

```bash
# Backend (FastAPI + Redis) — port 8001 en dev
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
redis-server &
uvicorn app.main:app --reload --host 0.0.0.0 --port 8001

# Frontend (Next.js)
cd frontend
npm install
npm run dev
```

Détail complet (quirk de port en dev, validation avant commit, tests) dans la section *Stack et démarrage* de `ARCHITECTURE.md`.
