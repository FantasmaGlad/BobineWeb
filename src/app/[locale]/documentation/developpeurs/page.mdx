# Documentation développeurs

Cette page reste volontairement courte : la référence technique complète (architecture, modèle de données, contrat réseau, API HTTP/WebSocket) vit dans le dépôt et reste la source de vérité.

- **[docs/ARCHITECTURE.md](https://github.com/FantasmaGlad/Bobine/blob/main/docs/ARCHITECTURE.md)** — stack, architecture multi-worker, modèle de données, référence API.
- **[Dépôt GitHub](https://github.com/FantasmaGlad/Bobine)** — code source, Issues, Discussions, Releases.

## Stack en bref

Backend Python (FastAPI, multi-worker) + Redis + SQLite ; frontend Next.js/TypeScript ; kiosque Chromium sur Debian 13 ; `install.sh` (Bash) pour le déploiement ; assistant d'installation graphique en Rust (en cours).
