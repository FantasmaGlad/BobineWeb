### Installation & Execution Profile
- Primary Package : Bobine-5.0.7.apk (native Android ARM64 / x86_64 runtime on Aluminium OS)

### Architecture Technical Reference : Aluminium OS
- Operating System : Google Aluminium OS (convergence of Android 16+ bare-metal kernel and full desktop Chrome browser environment, internal codename Project Snowy).
- Supported CPU Architectures : ARM64 (Qualcomm Snapdragon X series, MediaTek Kompanio Ultra) and x86_64 (Intel Core Ultra).
- Advantages for Gym Studios : Instant wake, 10 to 18 hours battery life for mobile coach desk operation, native Android APK execution without virtualization overhead, zero fan noise on ARM configurations, plug-and-play USB4 / USB-C DisplayPort Alt Mode 4K60 HDMI output.
