Bobine Stable, the official release

The Stable channel publishes frozen releases identified by a Vx.y.z tag and shipped with release notes. It is the default channel of every installation and the one to use for a studio in daily operation.

What the Stable channel guarantees

  • One release per strict Vx.y.z tag, published on GitHub Releases with its notes.
  • The same files on every platform: Windows (x86-64 and ARM64), macOS Apple Silicon, Linux (.deb amd64/arm64, .rpm x86_64/aarch64, pacman x86_64/aarch64), Android, Android TV, and the Bobine Assistant.
  • A SHA-256 digest verified before any installation started from the application.

Install or go back to Stable

On the Linux appliance, Stable is the default. From a Beta or Canary installation, pick Stable in Settings, Software updates.

curl -fsSL https://bobine.fit/install.sh | sudo bash -s -- --channel=stable

Verify the downloaded file

GitHub shows the SHA-256 checksum of every file on the release page: compare it with your download (sha256sum on Linux and macOS, Get-FileHash on Windows).

The application re-checks the SHA-256 checksum of every update itself before installing it.

Frequently asked questions

How do I find the latest stable version of Bobine?

The download card on this page is read straight from GitHub Releases and shows the version, its publication date and its files.

Are Stable updates automatic?

The application offers one-click updates and can schedule them overnight; on Debian and Ubuntu, the official APT repository makes them available through apt upgrade, and the dnf (Fedora) and pacman (Arch Linux) repositories do the same with dnf upgrade and pacman -Syu.
