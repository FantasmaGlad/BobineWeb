# Utilisation

> Version provisoire — traduction anglaise à venir.

## Panneau d'administration

Accessible sur `http://bobine.local` : import et organisation des vidéos, fonds animés, cours audio et pistes radio ; création de plannings et playlists ; réglages, thèmes et langue.

## Cinéma membre

L'écran câblé affiche un menu de sélection ; les membres lancent un cours eux-mêmes. Les nouveaux imports y apparaissent automatiquement.

## Écran réseau

Une seconde sortie indépendante — choisissez ce qu'affiche chaque écran dans *Paramètres → Sortie vidéo*.

## Télécommande mobile

Ouvrez `http://bobine.local` sur un téléphone ; l'affichage s'adapte en télécommande pour le staff.

## Radio

Ouvrez l'écran radio sur un appareil dédié pour diffuser la musique d'ambiance en continu ; pilotage depuis l'onglet *Radio* de l'admin.
