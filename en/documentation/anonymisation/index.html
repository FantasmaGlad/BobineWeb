Anonymization

The site and the APT repository are also published as v3 onion services. A gym can install Bobine and read the documentation without revealing its IP address. It is also a test bench: a signed, anonymous and robust multi-OS deployment chain, for applications that must stay available in a crisis.

One-command install

The script installs Tor, fetches the key over Tor and stops if its fingerprint differs. Read it before running it; --dry-run simulates, --channel=beta or canary switches channel.

bash
curl -fsSL https://bobine.fit/install-tor.sh -o install-tor.sh
less install-tor.sh
bash install-tor.sh

Manual install

Same packages and same key as packages.bobine.fit. Primary key fingerprint: B77D 96D7 2F84 F36A CAA3 F872 9CBF 497D 829E E15A

bash
sudo apt install apt-transport-tor
curl -fsS --socks5-hostname 127.0.0.1:9050 http://rzvwjat5pidtxtwzcsvew7yc5ugfjvzz432ecpn3s5mlch4cs7vvmqad.onion/bobine.gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] tor+http://rzvwjat5pidtxtwzcsvew7yc5ugfjvzz432ecpn3s5mlch4cs7vvmqad.onion/ stable main" \
  | sudo tee /etc/apt/sources.list.d/bobine-onion.list
sudo apt update && sudo apt install bobine
