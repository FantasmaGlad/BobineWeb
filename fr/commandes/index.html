Commande bobine

Chaque commande, ses arguments et ses codes de sortie, tels que les imprime bobine --help. Toute action de l'interface existe en ligne de commande ; --json rend une réponse lisible par une machine.

CommandesAPI HTTP

Options communes

--host
machine à piloter (défaut : 127.0.0.1, ou BOBINE_HOST)
--port
port de Bobine (défaut : port réel de la machine locale, ou BOBINE_PORT)
--timeout
délai d'une requête (défaut : 30 s, ou BOBINE_TIMEOUT)
--json
réponse JSON brute sur stdout
--verbose
détail sur stderr (-vv : requêtes et réponses)
--quiet
erreurs seulement
--no-color
sans couleur (aussi : variable NO_COLOR)

Codes de sortie

0
succès
1
échec de l'opération ou problème détecté
2
arguments ou valeur invalides
3
Bobine injoignable
4
refusé par l'état courant (conflit, interdit, indisponible)
5
cible introuvable
