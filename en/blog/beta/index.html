Bobine — Canal Bêta

Canal Bêta (accès anticipé). Lots de fonctionnalités et correctifs sélectionnés et testés avant leur passage en Stable — plus avancé que Stable, plus testé que Canary. Une version stable équivalente ou plus récente la remplace toujours automatiquement.

Pre-release curée : un lot de fonctionnalités/correctifs sélectionné par le mainteneur, publié manuellement — plus testé que Canary (qui suit chaque commit de main), moins que Stable. Republiée en place sur ce même tag mobile beta (jamais un nouveau tag par itération) à chaque nouveau lot. Une version stable équivalente ou plus récente la remplace toujours automatiquement.

Réservée aux utilisateurs ayant activé le canal Bêta (Réglages → Mises à jour, install.sh --channel=beta, ou l'assistant Tauri). Pour suivre chaque commit de main sans attendre un lot, voir le canal Canary.

Distributions Linux et méthodes d'installation

Dépôts signés GPG de packages.bobine.fit, canal Bêta : les mises à jour arrivent par le gestionnaire de paquets de la distribution.

Les binaires exigent glibc 2.38 ou plus récente : Debian 12, Ubuntu 22.04 LTS et RHEL 9 (et dérivés) ne sont pas pris en charge. La CI installe les paquets sur Ubuntu 24.04 (x86-64 et ARM64), Fedora et Arch Linux (x86-64) ; les autres distributions utilisent les mêmes paquets et ne sont pas testées séparément.

Installer depuis le dépôt (méthode recommandée)

  • Debian 13+, Ubuntu 24.04+, Linux Mint, Pop!_OS, Zorin OS (APT) : 
    curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] https://packages.bobine.fit/debian/ beta main" | sudo tee /etc/apt/sources.list.d/bobine.list
sudo apt update && sudo apt install bobine
  • Fedora, Nobara, RHEL 10+, AlmaLinux 10+, Rocky Linux 10+ (DNF) : 
    sudo rpm --import https://packages.bobine.fit/bobine.gpg
# Fedora 41+ (DNF 5)
sudo dnf config-manager addrepo --from-repofile=https://packages.bobine.fit/fedora/bobine-beta.repo
# Fedora 40 et antérieures, famille RHEL (DNF 4) : sudo dnf config-manager --add-repo https://packages.bobine.fit/fedora/bobine-beta.repo
sudo dnf install bobine
  • Arch Linux, EndeavourOS, CachyOS, Manjaro (pacman) : 
    curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key B77D96D72F84F36ACAA3F8729CBF497D829EE15A
printf '\n[bobine]\nServer = https://packages.bobine.fit/arch/beta/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu bobine

Installer un paquet autonome (hors ligne)

Téléchargez le paquet de votre architecture dans le tableau ci-dessus, puis :

sudo apt install ./bobine_beta_amd64.deb
sudo dnf install ./bobine-beta.x86_64.rpm
sudo pacman -U ./bobine-beta-x86_64.pkg.tar.zst

Vérifier l'intégrité des fichiers téléchargés

SHA256SUMS liste l'empreinte de chaque fichier de la release ; SHA256SUMS.asc en est la signature détachée, faite avec la clé qui signe aussi les dépôts de paquets (empreinte B77D 96D7 2F84 F36A CAA3 F872 9CBF 497D 829E E15A).

curl -fsSL https://packages.bobine.fit/bobine.gpg | gpg --import
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
