Report a vulnerability

Report security issues in the Bobine software, website or signed package repositories privately. Encrypt your report with the key below and check its fingerprint on at least two channels before sending.

Reports open Ed25519 + Curve25519 Key expires 2028-10-06 security.txt signed (RFC 9116)

3-Step Private Report

1.

Retrieve and verify the key

Fetch the public key, then compare the fingerprint with the table below and with the copy published in the GitHub repository:

Terminal (Bash)
gpg --locate-keys security@bobine.fit && gpg --fingerprint security@bobine.fit
Expected fingerprint: 23CA D324 C507 FB0F 97E6 AECA 6E4C 020E F8BD FEB2. A key whose fingerprint differs on any channel must not be used.
2.

Encrypt your report

Encrypt the report for the security key. To receive an encrypted reply, attach your own public key:

Terminal (Bash)
gpg --armor --encrypt --recipient security@bobine.fit report.txt
Your own key pair: gpg --quick-generate-key "Your Name <you@example.org>" future-default default 2y then gpg --armor --export you@example.org. Never share your private key. Without PGP, use the private GitHub report.
3.

Send it

Send the encrypted file (report.txt.asc) to the security address, or open a private report on GitHub:

E-mail
security@bobine.fit
