Bobine on Tor: .onion mirror and Linux package repositories

To install and update Bobine without revealing your IP address, the site and official Linux package repositories (Debian, Fedora, Arch) are also offered as onion services. It is a mirror of the official site and repositories: packages remain signed by the same key.

Fast Installation

Install Bobine over Tor in 1 line

The install-tor.sh script handles all configuration steps and verifies the OpenPGP key signature automatically.

bash · curl
curl -fsSL https://bobine.fit/install-tor.sh | bash
  • Switch channels with --channel=stable, --channel=beta, or --channel=canary. Use --dry-run to inspect actions without installing.
Manual Setup

Or step by step for APT (Debian, Ubuntu, Mint)

Configure apt-transport-tor, import the verified key into /etc/apt/keyrings, and register the .onion repository source.

/etc/apt/sources.list.d/bobine-onion.list
sudo apt install apt-transport-tor
curl -fsS --socks5-hostname 127.0.0.1:9050 \
  http://rzvwjat5pidtxtwzcsvew7yc5ugfjvzz432ecpn3s5mlch4cs7vvmqad.onion/bobine.gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] \
  tor+http://rzvwjat5pidtxtwzcsvew7yc5ugfjvzz432ecpn3s5mlch4cs7vvmqad.onion/ stable main" \
  | sudo tee /etc/apt/sources.list.d/bobine-onion.list
sudo apt update && sudo apt install bobine

FAQ

Frequently asked questions

Can Bobine be installed over Tor?

Yes, on Debian, Ubuntu and Linux Mint (APT), on Fedora and derivatives (DNF) and on Arch Linux and derivatives (Pacman): the three official repositories are also served over .onion, with the same packages signed by the same key.

Can the Beta or Canary channel be followed over Tor?

Yes: the .onion repositories publish all three channels, stable, beta and canary. install-tor.sh --channel=beta (or canary) sets up the matching source for APT, DNF or Pacman.

What about Fedora or Arch Linux?

The Fedora (DNF) and Arch Linux (Pacman) repositories are served over .onion like the APT repository, with the same signing key; install-tor.sh detects the family and configures the package manager. Installing over Tor was tried in Debian, Fedora and Arch containers, not yet on real machines. The same repositories are still served over HTTPS on packages.bobine.fit.

Is the Tor mirror complete?

It carries the static site (documentation, comparisons, blog); the hardware store and the Baamix assistant are left out.
