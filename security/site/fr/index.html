Signaler

1. Récupérez la clé et comparez son empreinte avec celle ci-dessus :

gpg --locate-keys security@bobine.fit
gpg --fingerprint security@bobine.fit

2. Chiffrez le rapport. Joignez votre propre clé publique pour recevoir une réponse chiffrée :

gpg --armor --encrypt --recipient security@bobine.fit report.txt

3. Envoyez le fichier chiffré à security@bobine.fit, ou ouvrez un signalement privé sur GitHub.
