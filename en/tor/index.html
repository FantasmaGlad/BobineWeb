Bobine on Tor: .onion mirror and APT repository

To install and update Bobine without revealing your IP address, the site and the official APT repository are also offered as onion services. It is a mirror of the official site and repository: packages remain signed by the same key.

The onion addresses

  • Site: http://bobinedaoki42tt33rxacmtaab2gxvxb2orqgcyhvowv3aggxhruvrid.onion/
  • APT repository: tor+http://rzvwjat5pidtxtwzcsvew7yc5ugfjvzz432ecpn3s5mlch4cs7vvmqad.onion/
  • The hardware store and the Baamix assistant are not offered on the mirror: they rely on affiliate links and third-party services.
  • The mirror is hosted by the maintainer, keeps no visit log, and runs on a best-effort basis.

Installing Bobine over Tor on Debian, Ubuntu or Mint

The install-tor.sh script performs the five steps and stops if the key fingerprint differs from the published one; the --dry-run option installs nothing. The update channel (Stable, Beta or Canary) is chosen with --channel=stable, --channel=beta or --channel=canary; without the option, the script asks on a terminal and falls back to Stable otherwise. Read it before running it:

curl -fsSL https://bobine.fit/install-tor.sh | bash

Or by hand

The same steps, one at a time. The last word of the deb line is the APT suite, hence the channel: stable, beta or canary, all three being published by the onion repository:

sudo apt install apt-transport-tor
curl -fsS --socks5-hostname 127.0.0.1:9050 \
  http://rzvwjat5pidtxtwzcsvew7yc5ugfjvzz432ecpn3s5mlch4cs7vvmqad.onion/bobine.gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] \
  tor+http://rzvwjat5pidtxtwzcsvew7yc5ugfjvzz432ecpn3s5mlch4cs7vvmqad.onion/ stable main" \
  | sudo tee /etc/apt/sources.list.d/bobine-onion.list
sudo apt update && sudo apt install bobine

Checking the key

Compare the primary key fingerprint with the one at https://packages.bobine.fit/bobine.gpg: B77D 96D7 2F84 F36A CAA3 F872 9CBF 497D 829E E15A. apt rejects any package whose signature does not match.

Frequently asked questions

Can Bobine be installed over Tor?

Yes, on Debian, Ubuntu and Linux Mint (APT), on Fedora and derivatives (DNF) and on Arch Linux and derivatives (Pacman): the three official repositories are also served over .onion, with the same packages signed by the same key.

Can the Beta or Canary channel be followed over Tor?

Yes: the .onion repositories publish all three channels, stable, beta and canary. install-tor.sh --channel=beta (or canary) sets up the matching source for APT, DNF or Pacman.

What about Fedora or Arch Linux?

The Fedora (DNF) and Arch Linux (Pacman) repositories are served over .onion like the APT repository, with the same signing key; install-tor.sh detects the family and configures the package manager. Installing over Tor was tried in Debian, Fedora and Arch containers, not yet on real machines. The same repositories are still served over HTTPS on packages.bobine.fit.

Is the Tor mirror complete?

It carries the static site (documentation, comparisons, blog); the hardware store and the Baamix assistant are left out.
