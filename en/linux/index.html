Quick Installation & Repositories

Install Bobine with a single terminal command.

Each distribution family has a dedicated, cryptographically signed repository. Select your distribution and update channel to get the exact install command instantly.

# 1. Importer la clé de signature OpenPGP officielle
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://packages.bobine.fit/bobine.gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg

# 2. Configurer le dépôt APT officiel Bobine (stable)
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] \
  https://packages.bobine.fit/debian/ stable main" \
  | sudo tee /etc/apt/sources.list.d/bobine.list

# 3. Mettre à jour et installer Bobine
sudo apt update && sudo apt install bobine

Audiovisual Architecture

Why Bobine thrives on Linux.

Built without unnecessary bloat, Bobine relies on the Linux kernel's hardware acceleration to play video with low resource use.

Direct VA-API & NVDEC decoding at 60 fps

Offload the entire video decoding pipeline to your Intel, AMD, Qualcomm Adreno or NVIDIA GPU. Even on silent fanless mini-PCs or refurbished laptops, playback remains buttery-smooth with minimal thermal footprint.

  • Hardware decoding for H.264, HEVC / H.265, VP9 and AV1
  • Independent multi-screen HDMI output in native fullscreen
  • Zero tearing or frame drops (V-Sync Wayland / X11)

Hardened appliance with Systemd watchdog

In appliance mode, Bobine boots directly into the projection screen without displaying any desktop chrome. The systemd service is sandboxed and monitored by a systemd watchdog (checked every 30 seconds).

  • Silent boot straight into the classroom or kiosk display
  • Automatic restart at the next check after an unexpected failure
  • Automatic and secure mounting of removable instructor media

100% Offline, zero subscriptions, zero cloud

Your schedules, videos, and member data remain strictly on your local machine. No internet connection is ever needed to run classes, trigger automation, or manage the cinema kiosk.

  • Instant local control from any smartphone or tablet
  • Zero accounts needed, zero telemetry or tracking
  • AGPL-3.0 open-source license: you own your equipment

Seamless updates with your operating system

Say goodbye to manual tarballs and scattered binaries: Bobine updates naturally with your routine `apt upgrade`, `dnf upgrade`, or `pacman -Syu` workflows.

  • Strict FHS binary parity compliance (/usr/lib/bobine)
  • Cryptographically signed with official OpenPGP key
  • Seamless rollback to Stable at any time without data loss

Frequently asked questions

Is there a Bobine package for Fedora?

Yes: an .rpm package (bobine-x.y.z-1.x86_64.rpm) and a signed dnf repository, on x86_64 and aarch64.

Is there a Bobine package for Arch Linux?

Yes: a pacman package (bobine-x.y.z-1-x86_64.pkg.tar.zst) and a signed [bobine] repository, on x86_64 (aarch64 for Arch Linux ARM).

Which distribution for a dedicated 24/7 appliance?

Minimal Debian 13 remains the reference: it is what the install.sh script targets. The .rpm and pacman packages are meant for Linux desktops.

Does Bobine run on Bazzite or Fedora Silverblue?

Immutable distributions do not suit the kiosk appliance, because the system is read-only there.
