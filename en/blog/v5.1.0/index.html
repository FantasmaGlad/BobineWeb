Bobine V5.1.0

These release notes are shown in their original language, usually French.

This version mentions Tor: installing and updating Bobine anonymously.

Bobine

La version 5.1.0 « Coco » succède à 5.0.7 « Aurora ». Bobine écoute désormais sur le port 1903 et s'ouvre sans code PIN sur le réseau local, VPN compris : une garde d'origine refuse toute action venue d'une page web tierce, rebinding DNS compris. Tout ce que fait l'interface se pilote maintenant par une API REST, par des fichiers de configuration JSON et par la nouvelle commande bobine, avec un diagnostic typé et des journaux en JSON stable : un script ou un agent externe peut diagnostiquer et conduire Bobine. L'installation tient en une commande, y compris sous Windows avec install.ps1, qui vérifie la signature des empreintes sans GnuPG ; les mises à jour peuvent passer par Tor, lancé seulement le temps nécessaire.

Installer depuis les dépôts signés

Les dépôts APT, DNF et pacman sont contrôlés et signés avant leur publication sur packages.bobine.fit. Les commandes ci-dessous installent le canal stable.

Debian, Ubuntu et dérivés (APT)

curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/bobine.gpg
echo "deb [signed-by=/etc/apt/keyrings/bobine.gpg] https://packages.bobine.fit/debian/ stable main" | sudo tee /etc/apt/sources.list.d/bobine.list
sudo apt update && sudo apt install bobine

Fedora et dérivés (DNF)

sudo rpm --import https://packages.bobine.fit/bobine.gpg

# DNF 5 (Fedora 41 et plus)
sudo dnf config-manager addrepo --from-repofile=https://packages.bobine.fit/fedora/bobine-stable.repo

# DNF 4
sudo dnf config-manager --add-repo https://packages.bobine.fit/fedora/bobine-stable.repo

sudo dnf install bobine

Arch Linux et dérivés (pacman)

curl -fsSL https://packages.bobine.fit/bobine.gpg | sudo pacman-key --add -
sudo pacman-key --lsign-key B77D96D72F84F36ACAA3F8729CBF497D829EE15A
printf '\n[bobine]\nServer = https://packages.bobine.fit/arch/stable/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu bobine

Pour changer de canal, remplacez stable par beta ou canary dans l'URL du dépôt et dans le nom du fichier .repo.

Pour l'appliance Debian 13, le script d'installation reçoit le canal en paramètre :

sudo ./install.sh --channel=stable

À savoir — L'adresse historique https://apt.bobine.fit redirige vers le dépôt unique https://packages.bobine.fit.

Vérifier l'intégrité des fichiers

Chaque release publie SHA256SUMS et SHA256SUMS.asc, signés avec la clé OpenPGP d'empreinte B77D 96D7 2F84 F36A CAA3 F872 9CBF 497D 829E E15A.

curl -fsSL https://packages.bobine.fit/bobine.gpg | gpg --import
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

À savoir — La même clé signe les dépôts de paquets et les sommes de contrôle des releases.

CE QUI CHANGE DANS LA VERSION 5.1.0

1. Port 1903 et liens d'accès

  • Port d'écoute par défaut 1903, repli de 1904 à 1913 s'il est occupé ; une appliance déjà installée garde son port, l'Assistant reconnaît 1903 et 8000.
  • Réglages et API listent chaque adresse d'accès (boucle locale, Wi-Fi, Ethernet, VPN, nom .local réel) avec ses pages.
  • Sur un poste de bureau, quand le port 80 est libre et permis, il redirige vers Bobine : http://bobine.local s'ouvre sans port.

2. Accès sans PIN, protégé par une garde d'origine

  • Le code PIN, les sessions et l'appairage par code disparaissent ; les anciens réglages sont migrés.
  • Une requête modifiante ou un WebSocket venu d'une autre origine est refusé (403 cross_origin), rebinding DNS compris ; la commande bobine, les scripts et l'Assistant, sans en-tête Origin, restent admis.
  • Noms admis pour l'interface : adresse IP, nom sans point, .local, .lan, .home, .onion, *.ts.net (Tailscale), nom de la machine, et la liste de BOBINE_ALLOWED_HOSTS.

3. Pilotage complet : API, configuration JSON, diagnostic, commande bobine

  • Lecture et radio par REST : POST /api/playback/{canal}/{action} et POST /api/radio/{sortie}/{action}, avec les mêmes commandes que le WebSocket de l'interface ; une commande en erreur ne ferme plus la connexion WebSocket.
  • Configuration en fichiers JSON : 14 fichiers, un par type de réglage (un planning par canal, playlists vidéo et radio, annonces, sorties radio, réglages…) ; POST /api/config/apply compare à blanc par défaut et applique tout ou rien, en listant chaque erreur.
  • Diagnostic : GET /api/diagnostics/system rend des constats à code stable triés par gravité, avec leur remède ; une sonde en échec vaut unknown, jamais une erreur 500.
  • Journaux : GET /api/logs en JSON stable, horodatage UTC (changement d'heure compris), filtres par niveau et par date, archives et traces rattachées.
  • Commande bobine : status, diagnose, logs, playback, radio, config export|apply, settings get|set, update check|apply|status, version ; --json pour une sortie machine, --host pour piloter une autre machine, codes de sortie de 0 à 4.

4. Mises à jour

  • Mises à jour par Tor, activables à côté du canal : Tor démarre pour la recherche et le téléchargement, puis s'arrête après cinq minutes d'inactivité.
  • Une mise à jour planifiée est reportée au lendemain si une lecture, le mode coach ou un rappel radio est en cours.
  • Android et Android TV n'ont plus de mise à jour planifiée.

5. Installation en une commande

  • install.ps1 joint à chaque release : x64 ou ARM64 détecté, -Channel, vérification de SHA256SUMS et de sa signature OpenPGP sans GnuPG, installation silencieuse ; -Tor (PowerShell 7.2+) télécharge par Tor Browser ou le service tor.
  • Manifestes winget générés à chaque Stable ; cask Homebrew fantasmaglad/bobine/bobine.

6. Écrans TV et interface

  • Vitrine /cinema en plein écran ; touches de chaîne de la télécommande pour passer au chapitre suivant ou précédent.
  • Un refus de la radio verrouillée est signalé dans le tableau de bord ; l'annonce de mise à jour se ferme après 8 s.
  • Après une bascule de sortie, la page d'arrivée suit la nouvelle sortie ; plus de contour de focus au clic.
  • Barres de progression animées sans recalcul de mise en page, transitions explicites, bascule entre kiosque, cinéma et radio sans rechargement.
  • Android : verrou Wi-Fi faible latence.
  • 15 thèmes (retrait du thème Onyx).

7. Import

  • Archives tar (.tar, .tar.gz, .tgz, .tar.xz, .tar.bz2) en plus du ZIP, format reconnu au contenu ; chemins absolus, traversées, liens et fichiers spéciaux refusés avant toute écriture.
  • Cours audio en .oga et .opus.

Subtilités à connaître

  • Nouveau port : un signet vers :8000 est à remplacer par :1903 sur les postes de bureau et Android ; une appliance déjà installée garde son port.
  • Accès sans PIN : tout appareil du réseau local ou du VPN peut ouvrir l'interface ; la garde d'origine protège des pages web tierces, pas d'un appareil du réseau.
  • Nom hors liste : un nom de domaine propre au réseau s'ajoute dans BOBINE_ALLOWED_HOSTS.
  • Tor : demande le programme tor sur la machine (paquet tor, Homebrew) ; Bobine ne l'installe pas.
  • Archives .7z : non prises en charge à l'import.
  • macOS : Apple Silicon uniquement, signature ad hoc. Windows : installeurs non signés, SmartScreen peut avertir.
