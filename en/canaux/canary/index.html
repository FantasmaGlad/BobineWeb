How the Canary works

  • A single GitHub release, on the moving tag canary, republished in place on every push to the main branch.
  • Fixed file names (Bobine-canary.apk, Bobine-TV-canary.apk, bobine_canary_amd64.deb, bobine-canary.x86_64.rpm, bobine-canary-x86_64.pkg.tar.zst, Bobine-Setup-canary.exe, Bobine-canary.dmg).
  • Automatically generated release notes: the commit log since the latest Stable.
  • Updates are detected by comparing commits.

Join or leave the Canary

In Settings, Software updates, choose the Canary channel. On the Linux appliance or from the Bobine Assistant:

curl -fsSL https://bobine.fit/install.sh | sudo bash -s -- --channel=canary

Before you install

The Canary may contain regressions: it has had no curation. For a studio in daily operation, prefer Stable. Going back to Stable stays possible at any time, without losing data.

Verify the downloaded file

GitHub shows the SHA-256 checksum of every file on the release page: compare it with your download (sha256sum on Linux and macOS, Get-FileHash on Windows).

The application re-checks the SHA-256 checksum of every update itself before installing it.

Frequently asked questions

What is Bobine Canary?

It is Bobine's rolling update channel: a release rebuilt automatically on every commit to the main branch, with no curation, to try changes as early as possible.

Where can I download Bobine Canary?

The Canary files (Windows, macOS, Linux, Android, Android TV) are listed in the download card on this page, read from GitHub Releases.

Is the Canary suitable for a studio in daily operation?

No, it is meant for following development. For daily operation, the Stable channel is recommended.
